### [GTFS Visualiser](https://gtfs.blrtransit.com)
##### Inspired by gtfs.vision

#### Why
Needed a simple tool to visualise gtfs feeds created locally or working with locally to confirm, validate, and explore.

#### Features

- Stop cards, timetable
- Trip cards, trip timetable
- Route cards, route departure timings
- Heatmap layer
- Filter agencies, routes, or stop sequences in sidebar
